# Security

## Reporting a vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

If you find a security issue in Cortex Data, please report it privately —
open a [GitHub Security Advisory](https://github.com/sidneysimas/cortex-data/security/advisories/new)
on this repository, or contact the maintainer directly.

Please include as much of the following as you can:

- Type of issue (e.g. injection, auth bypass, information disclosure, etc.)
- Full paths of source file(s) related to the issue
- The affected code location (tag/branch/commit or direct URL)
- Any special configuration required to reproduce it
- Step-by-step reproduction instructions
- Proof-of-concept or exploit code, if possible
- Impact of the issue, including how it could be exploited

This information helps triage the report faster.
