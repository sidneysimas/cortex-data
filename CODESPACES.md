# Set up Cortex Data on Codespaces
Use a preconfigured Codespace to get Cortex Data up and running quickly.

## Prerequisites
You will need a GitHub account and to be logged in to use Codespaces.

### Step 1: Create a Codespace (~5 minutes)

[![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/sidneysimas/cortex-data?quickstart=1)

### Step 2: Run the app
The codespace is a VSCode development environment in the cloud. Once the Codespace is created, start Cortex Data with the following steps:

* A toast about port forwarding will appear, click the **Open in Browser** button.
* You will see the Cortex Data app!
